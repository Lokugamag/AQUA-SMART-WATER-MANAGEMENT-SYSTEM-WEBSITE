# AQUA Website

A responsive, multi-page website for AQUA Smart Water Management Solutions.

## Website Pages

- Home
- About Us
- Products
- How It Works
- Contact

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## How to Run

1. Open the AQUA-WEBSITE folder in Visual Studio Code.
2. Add the approved logo and images.
3. Open index.html using Live Server.
4. Test all website pages and navigation links.

## Before Publishing

- Replace placeholder text with approved company information.
- Verify product details and technical specifications.
- Add official contact details.
- Connect the contact form to a secure backend.
- Test the website on desktop, tablet and mobile devices.
- Enable HTTPS on the production website.

## Security

- Never store passwords or API keys in frontend files.
- Validate submitted data on the server.
- Use HTTPS for production.
- Apply spam protection and rate limiting to the contact form.
